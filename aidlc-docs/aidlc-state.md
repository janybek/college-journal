## Что перенести в следующие юниты

- **Юнит 2 и дальше:** когда появятся листы пар, оценок и посещаемости, добавить для них запрет удаления («используется»). Сейчас он есть только для группы со студентами или предметами и для сотрудника с предметами.
- **Юнит 3:** ограничение числа попыток входа (вместе с кешем); не делать два фоновых запроса при каждой загрузке страницы (словарные правки кешировать на день); ограничение времени ожидания ответа (но не для импорта).
- **Новое от владельца 22.11.2026 — учесть в планах юнитов 3–6 (пока нигде не заложено):** зачётная неделя (даты; идут ли обычные пары) и государственный экзамен (по каким предметам, у каких групп, даты). Спросить владельца, что журнал должен с ними делать: только показывать в расписании или вести ведомость.
- **Позже:** сотрудник не должен сбрасывать пароль или отключать сам себя; нельзя снимать роль преподавателя, пока за ним закреплены предметы; огромный объявленный диапазон в Excel может подвесить вкладку.

## Особенности этого компьютера

- На `localhost:5173` живёт другой проект владельца («Прораб») со своим сервис-воркером. Стенд журнала — только на 5273.
- Если чат был открыт не в папке проекта, запуск стенда по имени из `.claude/launch.json` может поднять чужой проект. Надёжный способ: `npm run dev` в папке проекта и открыть `http://localhost:5273`.
- Агенты из `.claude/agents/` становятся доступны как типы агентов только в чате, запущенном в папке проекта.
