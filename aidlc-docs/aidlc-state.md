## Особенности этого компьютера

- На `localhost:5173` живёт другой проект владельца («Прораб») со своим сервис-воркером. Стенд журнала — только на 5273.
- Если чат был открыт не в папке проекта, запуск стенда по имени из `.claude/launch.json` может поднять чужой проект. Надёжный способ: `npm run dev` в папке проекта и открыть `http://localhost:5273`.
- Агенты из `.claude/agents/` становятся доступны как типы агентов только в чате, запущенном в папке проекта.
