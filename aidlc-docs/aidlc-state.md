## Что перенести в следующие юниты

- **Юнит 2 и дальше:** когда появятся листы пар, оценок и посещаемости, добавить для них запрет удаления («используется»). Сейчас он есть только для группы со студентами или предметами и для сотрудника с предметами.
- **Юнит 3:** ограничение числа попыток входа (вместе с кешем); не делать два фоновых запроса при каждой загрузке страницы (словарные правки кешировать на день); ограничение времени ожидания ответа (но не для импорта).
- **Новое от владельца 22.11.2026 — учесть в планах юнитов 3–6 (пока нигде не заложено):** зачётная неделя (даты; идут ли обычные пары) и государственный экзамен (по каким предметам, у каких групп, даты). Спросить владельца, что журнал должен с ними делать: только показывать в расписании или вести ведомость.
- **Из доработки 3 (силлабус на сайте):** (1) если при «Утвердить» Google оборвал запись, деканату нажать «Утвердить» ещё раз — до повтора пары стоят на темах версии «на утверждении», а возврат вместо повтора может оставить проведённую пару без темы; починить при юните 3 (отметка «проведена»); (2) «Изменить» копирует утверждённую версию не одной записью — при сбое черновик без части разделов; (3) две версии «на утверждении» одного силлабуса (два «Заполнить» одновременно) обе в очереди; (4) любой черновик, даже пустой, не даёт удалить свою дисциплину и преподавателя; (5) на вычитку носителем — все новые кыргызские ключи `sform.*`, `review.*`, `syllabus.status.*`, `syllabus.state.*`, `error.syllabus_locked`, спорные «ЛИ», «Долбоор», «Көндүмдөр».
- **Юнит 4 (из юнита 3):** окно пары считает пару проведённой по статусу running/closed; когда QR начнёт ставить running, пара без отметок покажет всех «Нет отметки» — решить в плане юнита 4 (по сохранённым отметкам или «Был» по умолчанию). Ключ `journal.marks.noMark` (ky «Белги коюлган эмес») — на вычитку.
- **Юнит 3 — сделать до начала:** сверить подгруппы по данным секретаря (правило 5); журнал изменений отметок (правило 6); проверка «курс ↔ семестр силлабуса» (правило 7). **Сразу после доработки 4:** прикрепляемый файл силлабуса, вкладки 4–8 необязательные (правило 4). **До юнита 4:** единая схема баллов колледжа в настройках (правило 8), зачётная неделя и гос. экзамены (правило 9). **Перед запуском для всех:** вычитка кыргызского (правило 10).
- **В самом конце (решение владельца):** ИИ проверяет выбранные места сайта — первый кандидат: разбор загруженного силлабуса в титул и тематический план как черновик.
- **Позже:** сотрудник не должен сбрасывать пароль или отключать сам себя; нельзя снимать роль преподавателя, пока за ним закреплены предметы; огромный объявленный диапазон в Excel может подвесить вкладку.

## Особенности этого компьютера

- На `localhost:5173` живёт другой проект владельца («Прораб») со своим сервис-воркером. Стенд журнала — только на 5273.
- Если чат был открыт не в папке проекта, запуск стенда по имени из `.claude/launch.json` может поднять чужой проект. Надёжный способ: `npm run dev` в папке проекта и открыть `http://localhost:5273`.
- Агенты из `.claude/agents/` становятся доступны как типы агентов только в чате, запущенном в папке проекта.
