Исправлено текстом в `aidlc-state.md` (раздел выкладки, при выкладке): «Откат на 72fb36b — без нужды не делать. Перед откатом `npm run serve:backup` и дождаться "Копия сделана". При возврате вперёд скопировать недостающие `.bin` из `C:\JournalBackups\files` в папку `files` базы (или `serve:restore` последней копии); до этого студент видит "Файл силлабуса не найден"».
