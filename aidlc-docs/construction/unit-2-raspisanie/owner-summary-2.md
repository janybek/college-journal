# Юнит 2: что изменится по вашим трём замечаниям

21 ноября 2026 · для владельца проекта · полный план: `plan.md` в этой же папке, раздел «Дополнение от 21.11.2026» (задачи 14–20)

## 1. Звонки — из списка

На экране «Настройки семестра» время начала пары больше не вписывается. У каждой пары — выпадающий список: каждые 5 минут с 07:00 до 22:25. Поставить 02:00 вместо 14:00 нельзя: такого времени в списке нет. Пара по-прежнему длится 90 минут, конец считается сам.

## 2. День недели открывает шаблон

На экране «Расписание» в режиме «По группе» название дня (понедельник–пятница) стало ссылкой. Нажали «Среда» у группы 02-1 — открылся «Шаблон недели» группы 02-1, столбец среды подсвечен. У субботы ссылки нет: в шаблоне её нет. В режиме «По преподавателю» ссылки тоже нет: там пары разных групп.

## 3. Темы — это силлабус преподавателя

**У преподавателя.** В «Моих предметах» у каждого предмета кнопка «Силлабус». На странице предмета:

- две вкладки — «1 семестр» и «2 семестр»; у текущего семестра темы стоят на парах с датами;
- кнопка **«Загрузить силлабус (Excel)»**: скачать шаблон, заполнить, загрузить. Журнал сначала показывает, сколько тем добавится и обновится и в каких строках ошибки, и только потом загружает;
- темы можно добавлять, править и удалять прямо на экране.

Преподаватель видит и меняет только свои предметы.

**У деканата.** Экран «Темы» остаётся: выбираете любой предмет и видите его силлабус по семестрам. Там же можно загрузить файл или поправить тему за преподавателя. Проректор только смотрит.

**Как выглядит файл преподавателя.** Один файл на год. Предмета и группы в файле нет — они берутся со страницы, с которой файл загружают. Одна строка — одна пара.

| Семестр | Модуль | № | Тема | Тип |
| --- | --- | --- | --- | --- |
| 1 | 1 | 1 | Введение в IT | лекция |
| 1 | 1 | 2 | Введение в IT | практика |
| … | | | | |
| 1 | 2 | 16 | Модуль 2 — экзамен | рубежный |
| 2 | 1 | 1 | Электронные таблицы | лекция |
| … | | | | |
| 2 | 2 | 16 | Модуль 2 — экзамен | рубежный |

- В каждом семестре темы и модули нумеруются заново, с 1. Сколько модулей — решает преподаватель.
- В файле и на экране пишем «Модуль» (раньше было «Юнит»). Файл со словом «Юнит» тоже примется.
- Тип — «лекция», «практика» или «рубежный».
- Если преподаватель ведёт один предмет в трёх группах, он загружает файл на странице предмета каждой группы. Файл подходит один и тот же.

**Что стоит знать.**

- На пары встают только темы текущего семестра. Темы другого семестра ждут своей очереди.
- Тему уже проведённой пары загрузка файла не меняет: журнал покажет ошибку в этой строке, остальные строки загрузит.
- В общем импорте деканата (темы сразу по многим предметам) появился обязательный столбец «Семестр».

## Вопросы к вам

К каждому вопросу — вариант, который я сделаю, если вы просто ответите «да».

1. **Как журнал узнаёт, какой сейчас семестр.** Предлагаю переключатель «Сейчас идёт: 1 семестр / 2 семестр» на экране «Настройки семестра», сначала стоит «1». В начале второго семестра деканат ставит новые даты, переключает на «2» и нажимает «Создать расписание» — на новые пары встают темы второго семестра. Уже проведённые пары не меняются. Подходит?
2. **Повторная загрузка силлабуса.** Преподаватель исправил файл и загрузил снова: темы с тем же семестром и номером обновятся, новые добавятся. Темы, которых в новом файле уже нет, журнал сам не удаляет — лишнюю преподаватель удаляет на экране. Так безопаснее: неполный файл ничего не сотрёт. Оставляем так?
3. **Список времени звонков.** С 07:00 до 22:25, шаг 5 минут. Хватит ли этого? Если пары бывают раньше 07:00 или нужен другой шаг — скажите.
