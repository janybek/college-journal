# Какие данные нужны для журнала

Список для секретаря или деканата. Всё, кроме студентов, нужно сейчас — для расписания и силлабусов. Удобнее всего прислать таблицами Excel: одна тема — один лист.

Сами файлы в чат с Claude и в папку проекта не кладём: репозиторий открытый. Владелец загружает их сам через сайт журнала («Импорт из Excel»).

## 1. Группы (пилот — 3 группы)

| Что | Пример |
| --- | --- |
| Название группы | 01-1 |
| Курс | 1 |
| Специальность | Сестринское дело |

## 2. Сотрудники

Преподаватели пилотных групп, деканат, проректор.

| Что | Пример |
| --- | --- |
| ФИО полностью | Асанова Айгуль Бакировна |
| Роль | преподаватель / деканат / проректор (можно две: деканат и преподаватель) |
| Язык интерфейса | кыргызский / русский |

Логины и временные пароли журнал выдаст сам.

## 3. Дисциплины этого семестра

По каждой специальности и курсу — список дисциплин.

| Что | Пример |
| --- | --- |
| Название дисциплины (как в учебном плане) | Информатика |
| Кредиты | 2 |
| Часы всего | 60 |
| Из них аудиторных | 36 |
| Из них СРС | 24 |

## 4. Кто что ведёт

| Дисциплина | Группа | Преподаватель |
| --- | --- | --- |
| Информатика | 01-1 | Асанова А. Б. |
| Информатика | 02-1 | Токтогулов Н. К. |

Если дисциплину в одной группе ведут два преподавателя (лекции один, практику другой) — отметить это отдельно.

## 5. Аудитории

Номера или названия аудиторий, где идут пары пилотных групп: 101, 204, «Компьютерный класс».

## 6. Звонки и семестр

- Расписание звонков: начало каждой пары (например 08:00, 09:40, 11:20, 13:30, 15:10, 16:50) и сколько длится пара.
- Дата начала и дата окончания текущего семестра.
- Какой это семестр: первый или второй.
- Нерабочие дни в семестре: праздники, каникулы, дни без занятий.

## 7. Расписание на неделю по каждой группе

| Группа | День | Пара | Дисциплина | Аудитория |
| --- | --- | --- | --- | --- |
| 01-1 | понедельник | 1 | Информатика | 204 |
| 01-1 | понедельник | 2 | Анатомия | 101 |

Если расписание по чётным и нечётным неделям разное — сообщить отдельно: сейчас журнал считает, что каждая неделя одинаковая.

## 8. Силлабусы

По каждой дисциплине от каждого преподавателя — его силлабус (как он есть сейчас, в Word или PDF). В нём нужны:

1. Общие сведения: курс, семестр, для какой специальности, кредиты, часы (всего, аудиторные, СРС), преподаватель.
2. Тематический план: темы по модулям, у каждой темы часы лекций и часы практики, где рубежный контроль.
3. Краткое описание каждой темы.

Шаблон Excel для загрузки в журнал появится после доработки; по присланным силлабусам проверим, что шаблон подходит.

## 9. Студенты — позже

Загружаем после того, как в журнале появится ограничение попыток входа (юнит 3). Понадобится:

| Что | Пример |
| --- | --- |
| ФИО полностью | Асанов Айдар Бакытович |
| Группа | 01-1 |
| Номер студенческого билета | 1002 |

## Вопросы, на которые нужен ответ словами

1. Бывает ли, что одну пару ведут сразу у двух групп (общая лекция потока)? Сейчас журнал такого не допускает.
2. Делится ли группа на подгруппы хотя бы по одной дисциплине? Сейчас считаем, что нет.
3. Бывает ли учебная суббота по шаблону, а не как разовый перенос?
4. Сколько пар в неделю у группы самое большее в день?
